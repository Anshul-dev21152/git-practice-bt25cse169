## Requirements

- A C++ compiler such as `g++`
- C++17 support

## Compile and run

Open a terminal in the repository folder. For each exercise, enter its folder, compile `main.cpp`, and run the program.

Example for addition:

```bash
cd exercise-01-addition
g++ -std=c++17 main.cpp -o program
./program
```

On Windows, run:

```powershell
.\program.exe
```

Repeat the same commands in the other exercise folders. Use the corresponding folder name.
